# 🛒 Teres Store

Website statis sederhana untuk toko aksesoris gadget fiktif **Teres Store**, dibuat sebagai tugas kuliah menggunakan HTML dasar.

🔗 **Demo:** https://esterbln.github.io/teres-store-html/

## ✨ Fitur Halaman

- **Beranda (`index.html`)**: profil singkat toko, keunggulan produk, alamat, dan kontak, serta tombol menuju halaman lain.
- **Data Produk (`DataProduk.html`)**: tabel berisi gambar, nama, kode, dan harga produk (case HP iPhone, tripod HP, headphone wireless).
- **Form Input (`FormInput.html`)**: formulir untuk memasukkan nama, kode, dan harga produk.

## 🧰 Teknologi

- HTML5

## 📁 Struktur Proyek

```
teres-store-html/
├── index.html        # Halaman beranda
├── DataProduk.html   # Halaman tabel produk
├── FormInput.html    # Halaman form input produk
├── images/           # Gambar produk dan screenshot
└── README.md
```

## 🚀 Cara Menjalankan

1. Clone repositori ini:
   ```bash
   git clone https://github.com/esterbln/teres-store-html.git
   ```
2. Masuk ke folder proyek:
   ```bash
   cd teres-store-html
   ```
3. Buka `index.html` dengan browser (klik dua kali), atau gunakan ekstensi **Live Server** di VS Code.
